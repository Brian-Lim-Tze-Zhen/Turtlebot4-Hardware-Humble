Which side does the robot pass you on?

The robot measures how far you stand beside its path when it first sees you, about 6.5 m away. If you are more than a threshold to its right, it passes on your right; otherwise it keeps right, the German way. Today's runs say the threshold should be 0.20 m, and that the robot's localization has to be checked before every run.

The rule, seen from above

The side is set by the first position sample. After that the side hold keeps it, unless you later read more than 0.30 m on the other side. So the threshold acts on one early, noisy estimate.

Why a few degrees matter

Today AMCL was off by 2–3.5° at the start of four runs. After the manual pose reset at 11:46 it was 3.5° off, and both following runs went LEFT for a centred walker. check_localization.py --fix measures this from the laser scan and corrects it before a run.

The procedure

  1. Send the robot to the start.
  2. Run check_localization.py --fix and repeat it until it prints OK (heading within 1°, position within 0.10 m).
  3. Start the run with side_switch_offset: 0.20.
  4. The first sample sets the side: offset −0.20 m or further right → keep LEFT; anything else → keep RIGHT. The side hold keeps it.

Based on 11 runs; the margins are a few centimetres (run 06 at −0.16, 5 Oct at −0.26). The simulation still uses 0.15 until this is tested there. The threshold does not change the hard swerve after the side is chosen.
